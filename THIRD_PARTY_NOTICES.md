# Third-Party Notices

AeroCalculator depends on B4A libraries and currently vendors two library archives under `Install/`.

The repository does not yet contain verified upstream license metadata for every vendored archive. Before distributing those archives as part of a release source package, verify and record the upstream license and redistribution terms in `docs/dependencies.md`.

This file is intentionally conservative: the presence of third-party code in the repository does not imply ownership or relicensing by the AeroCalculator project.
